# RapidJAM Configurator 利用ガイド

英語版: [USER_GUIDE.en.md](USER_GUIDE.en.md)

対象バージョン: 0.7.1（Windows x64 デスクトップ版）

RapidJAM Configurator は、RapidJAM コントローラーのボタン割り当て、入力モード、磁気スイッチ（Hall センサー）の設定を、USB 接続した状態で確認・変更するためのアプリです。非公式のコミュニティ製ツールで、MIT ライセンスで提供されます（[LICENSE](../LICENSE)）。無保証です。設定を書き込む前に、内容をよく確認してください。

## 1. 準備するもの

- Windows 10 / 11（x64）の PC
- Microsoft Edge WebView2 Runtime（Evergreen）。Windows 11 には通常入っています。アプリが起動しない場合は WebView2 Runtime をインストールしてください。
- RapidJAM 本体と USB ケーブル
- WebConfig/RNDIS モードで動作するファームウェア。コントローラーは `http://192.168.7.1` で応答する必要があります。モードの切り替え方法はファームウェアの案内に従ってください。

アプリはこのアドレスだけと通信します。インターネット接続や Node.js は不要です。

## 2. 起動と接続

1. ZIP を任意のフォルダーに展開し、`rapidjam-configurator.exe` を起動します。管理者権限は不要です。
2. RapidJAM を WebConfig/RNDIS モードにして、USB で PC に接続します。
3. 画面上部に RapidJAM の製品名とファームウェア情報が表示され、左下に「RapidJAM 接続中」と出れば接続できています。
4. 接続できない場合は、画面に「RapidJAM に接続できません」と表示されます。USB 接続と WebConfig/RNDIS モードを確認し、「再試行」を押してください。

接続後に左下の「デバイスに再接続」を押すと、設定を読み直せます。

## 3. 画面の見かた

| 場所 | 内容 |
| --- | --- |
| 上部 | 製品名・ファームウェア、Expert mode ボタン、表示言語の選択 |
| 左側 | 「ボタン割り当て」「磁気スイッチ調整」の切り替え、接続状態、「デバイスに再接続」、「ゲームパッドモードで再起動」、「接続診断情報」 |
| 中央 | 選択中の画面の内容 |
| 下部 | 保存状態（「未保存の変更があります」／「すべての変更を保存済みです」）、「変更を破棄」、「デバイスに保存」 |

### 表示言語

初回起動時は OS の言語に合わせ、日本語環境では日本語、それ以外では English で表示します。上部の言語メニューでいつでも切り替えられ、選んだ言語は次回以降も使われます。製品名、GPIO や CH の番号、HID のキー名などは、機器との対応を保つため英語のまま表示することがあります。

## 4. 変更を保存する

画面で行った変更は、次の2つを除いて「デバイスに保存」を押すまでデバイスに書き込まれません。

- 「変更を破棄」を押すと、保存前の編集内容を、最後に読み込んだ状態に戻します。
- 「校正結果を反映して保存」は、その場でデバイスに書き込みます（[7 章](#7-全チャンネルの自動校正)）。

保存中は USB ケーブルを抜いたり、アプリを終了したりしないでください。保存が終わると、アプリがデバイスから設定を読み直し、「RapidJAM に保存しました」と表示します。

## 5. ボタン割り当て

左側の「ボタン割り当て」を選びます。

### 入力モード

「入力モード」で、コントローラーが PC やゲーム機に対して名乗るプロトコルを選びます。選べるモードは次のとおりです。

- PC 向け: XInput、キーボード、汎用 HID
- ゲーム機向け: Nintendo Switch、Nintendo Switch Pro、PS3、PS4、PS5、P5 General、Xbox One、初代 Xbox、メガドライブミニ、NEOGEO mini、PCエンジン mini、イーグレットツー ミニ、アストロシティミニ、プレイステーション クラシック

モードの変更は保存後、コントローラーをゲームパッドモードで再起動してから実際に有効になります。ただし、画面上のボタン表記は選んだ時点で切り替わります。

「入力モードの詳細設定」には、モードに応じて次の項目が出ます。意味が分からない項目は変更しないでください。

- コントローラーの種類（Gamepad、Wheel、HOTAS、Guitar、Drums、Arcade stick。モードによって選べるものが異なります）
- 認証方式（なし、キー、USB ホスト、I2C）
- PS4 / PS5 / P5 General での、Share/Create と Touchpad の表記の入れ替え
- PS4 / PS5 でのコントローラー識別方式
- XInput と汎用 HID での、USB デバイス情報（製品名・製造元・バージョン）や Vendor ID / Product ID の上書き。誤った値を設定すると、PC やゲーム機に認識されなくなることがあります。

### ボタン表記

ボタン名は入力モードに連動します。たとえば、物理ボタンの割り当てが同じでも、次のように表示が変わります。

| 割り当て | XInput | Nintendo Switch | PS4 / PS5 |
| --- | --- | --- | --- |
| B1 / B2 / B3 / B4 | A / B / X / Y | B / A / Y / X | ✕ / ○ / □ / △ |
| L2 / R2 | LT / RT | ZL / ZR | L2 / R2 |
| S1 / S2 | Back / Start | − / + | Share（PS5 は Create）/ Options |
| A1 / A2 | Guide / （未使用） | Home / Capture | PS / Touchpad |

そのモードで使わないボタンは「（未使用）」と表示します。キーボードと汎用 HID、および一覧にないモードでは XInput の表記になります。

### チャンネルの割り当て

コントローラー図には、磁気スイッチ 16 個（CH0〜CH15）が表示されます。ボタンの薄い文字は、本体の物理ボタンに刻まれている文字や矢印で、入力モードや割り当てを変えても変わりません。前面の文字が、現在の設定での機能名です。

1. 図のボタンを選びます。右側に「CH14 · A」のように、チャンネル番号と刻印が表示されます。
2. 「ゲームパッド操作」で、そのチャンネルに割り当てる操作を選びます。「未割り当て」にするとボタンを無効にできます。
3. 保存前に変更したボタンは、図と一覧で変更済みと分かるように表示されます。

### キーボードモード

入力モードをキーボードにすると、割り当て画面が「キーボードの割り当て」に変わります。各チャンネルの現在のゲームパッド操作は変えられず、その操作に割り当てる HID キーを選びます。キーに対応しない操作には「キーボード HID の割り当てなし」と表示されます。

### GPIO の割り当て

画面の下部で GP0〜GP5 に割り当てる操作を選べます。ゲームパッドの操作のほか、Turbo、マクロ、アクセル、ブレーキ、Home、メニュー、ファンクション（Fn）なども指定できます。GP13〜GP15、GP25〜GP26、GP29 はアドオン用に予約されているため表示されません。

## 6. 磁気スイッチ調整

左側の「磁気スイッチ調整」を選びます。ボタンの反応する位置（アクチュエーションポイント）やラピッドトリガーを調整します。

### チャンネルの選択

- 図のボタンを押すと、そのチャンネルだけを選択します。
- Shift / Ctrl キーを押しながら押すと、複数のチャンネルを追加・解除できます。「すべて選択」で全チャンネルを選べます。
- 複数選択中の変更は、選択中のすべてのチャンネルに同じ値で反映されます。対象をよく確認してください。
- ストロークバーに表示されるのは、アクティブな 1 チャンネルだけです。

### ストロークバー

選択中のチャンネルについて、ADC29 の電圧から推定した現在のストローク量（mm）をライブ表示します。

- 青いマーカーがアクチュエーションポイントです。ラピッドトリガーが有効なときは、赤いマーカーがラピッドトリガーのしきい値です。
- マーカーはドラッグして動かせます。ドラッグ中はプレビューで、指（マウスボタン）を離すと編集中の設定に反映されます。保存するまではデバイスに書き込まれません。
- 数値やスライダーでも同じ値を設定できます。mm 単位の値は、保存時に校正範囲に対する割合から ADC 値へ換算されます。
- 「キー入力の推定」の ON/OFF は、取得した ADC 値と編集中の設定からの推定です。実際のゲームパッド入力ではなく、未保存の変更はコントローラーには反映されていません。
- 表示は HTTP で定期的に取得しているため、実際の動きより遅れることがあります。一時的に読み取れなかったときは、最後に取得した値を表示します。
- 校正が未実施または無効なチャンネルでは、ストロークを表示できません。

### 設定できる項目

- **アクチュエーションポイント**: 反応を開始する位置です。
- **ラピッドトリガー**: オンにすると、キーが戻り始めるとすぐにリセットします。オンのとき、ラピッドトリガーの有効範囲（しきい値）とノイズフィルター（許容範囲、0〜4095）を設定できます。オフのときは、このファームウェアでは ON/OFF ともにアクチュエーションポイントで判定されるため、リリースポイントの欄とマーカーは非表示です。再びオンにすると、保持されている値が表示されます。

値を変えると操作感が大きく変わります。保存したあと、ゲーム内などで安全に動作を確認してください。

### 標準モードと Expert mode

上部の「Expert mode」ボタンで切り替えます。初期状態は標準モードです。

| | 標準モード | Expert mode |
| --- | --- | --- |
| アクチュエーションポイント | 0.05〜1.30 mm（1.30 mm より深い範囲はバー上に斜線で表示） | 0.05 mm〜フルストローク量 |
| ラピッドトリガーのしきい値 | フルストローク量まで | フルストローク量まで |
| フルストローク量の設定 | 非表示（RapidJAM は 1.5 mm） | 0.5〜4.0 mm を 0.1 mm 刻みで設定 |

Expert mode に切り替えるときは、推奨されない設定ができる旨の確認が表示されます。選んだモードはこの PC 上のアプリに保存され、次回起動時も維持されます。

デバイスに 1.30 mm を超えるアクチュエーションポイントがすでに保存されていても、標準モードに切り替えただけでは値は変わりません。標準モードでその値を操作すると、1.30 mm 以下に収まります。

フルストローク量は機種ごとにこの PC のアプリへ保存されます。変更しても、表示上の mm への換算が変わるだけで、デバイスの ADC しきい値や未保存の状態は変わりません。「機種の既定値に戻す」でプリセットに戻せます。RapidJAM 以外の機種や、機種を判定できない場合、標準モードでは「この機種は通常モードではサポートされていません。Expert mode を使用してください。」と表示され、仮に 1.5 mm として扱います。

## 7. 全チャンネルの自動校正

校正は、未押下位置と押し込み位置を測り直す機能です。ファームウェアが ADC29 の電圧読み取りに対応している必要があり、未対応の場合はボタンが無効になります。

1. 「すべての磁気スイッチを校正」を選びます。
2. 未押下値の測定が始まります。測定中は、コントローラーのボタンに触れないでください。
3. 押下測定になったら、各ボタンを普段押す感覚で押し切り、離します。順番は問いません。測定が終わるまで指示に従ってください。押し切った状態を保持すると、測定値が取得されます。
   - 押し切り → 離す → 押し直す、を約3回繰り返します。押し直しの指示が出たら、もう一度ボタンを押してください。
   - 3回の押し込み量がそろわない場合は、最大5回まで押し直しを求めます。それでもそろわないチャンネルは「不安定」(オレンジ)になります。結果を確認し、必要に応じて再測定してください。
   - 押し切る前にボタンを離した場合は、その回の押し込みだけやり直します。
   - 完了したボタンは緑になります。黄色のボタンを押すとスキップできます。緑のボタンを押すと再測定できます。
   - 測定に失敗したチャンネルは、状態一覧から選んで再測定できます。
4. 全チャンネルが終わったら「測定を終了して結果を確認」を選びます。スキップしたチャンネルは校正されません。
5. 結果を確認します。未押下値、押下値、変化量、状態に不自然な値がないか見てください。問題があれば、適用せずに「キャンセル」してください。
6. 問題がなければ「校正結果を反映して保存」を選びます。この操作でデバイスに保存されます。保存後は、アクチュエーションポイントとリリースポイントの割合を保ったまま新しい校正範囲に換算されます。

校正中にボタンを操作したり USB を抜いたりすると、測定に失敗することがあります。異常な値が出たときは適用せず、接続とファームウェアの対応状況を確認してください。

## 8. ゲームパッドモードへの復帰

左側の「ゲームパッドモードで再起動」を選ぶと、RapidJAM は通常のゲームパッド動作に戻ります。このとき Configurator との接続が切れるのは正常です。もう一度設定するには、WebConfig/RNDIS モードに戻して再接続してください。

## 9. うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| アプリが起動しない | WebView2 Runtime がインストールされているか確認します。 |
| 接続できない | USB ケーブル、WebConfig/RNDIS モード、`192.168.7.1` への応答を確認し、「再試行」または「デバイスに再接続」を試します。 |
| 保存でエラーが出た | 設定が一部だけ書き込まれている可能性があります。再試行を繰り返す前に再接続し、デバイスから設定を読み直して実際の状態を確認してください。 |
| 校正を始められない | ファームウェアが ADC29 に対応しているか確認します。ライブ読み取りがタイムアウトした場合は、先にデバイスへ再接続してください。 |
| ストロークが表示されない | そのチャンネルが校正済みか確認します。ライブ読み取りに失敗していると「ADC29を読み取れません」と表示されます。 |
| Configurator で復旧できない | GP2040-CE WebConfig の復旧手順を利用してください。初期化やリセットは保存設定を失うことがあるため、手順を確認してから行ってください。 |

調査に使える技術情報は、左側の「接続診断情報」を開くと表示されることがあります。問題を報告するときは、この診断内容、アプリのバージョン、ファームウェアのバージョンを添えてください。

## 10. アプリが PC に保存するもの

言語、標準モード／Expert mode、機種ごとのフルストローク量は、WebView2 のデータ領域に保存されます。保存先は `%LOCALAPPDATA%\Goppa\rapidjam.configurator\EBWebView` で、EXE の隣ではありません。初期化したいときは、アプリを終了してこのフォルダーを削除してください。言語・モード・フルストローク量の設定が消えます。デバイス内の設定は消えません。
