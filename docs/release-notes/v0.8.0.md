# RapidJAM Configurator v0.8.0

## Highlights

**More reliable calibration for Hall-effect buttons.** Calibration now measures each button over several press and release cycles and flags results that do not agree, so the saved values are more trustworthy.

- Each button is pressed about three times (up to five if the presses disagree). The measured values come from these presses.
- Channels whose presses still disagree are marked "unstable" (orange), so you can check them and measure them again.
- The idle value is also re-measured after you release the button, which addresses the level shift seen after releasing and re-pressing a button.
- Idle and pressed positions use five samples per channel, and the median is used to ignore a single spike.
- Added "Calibrate selected buttons" to calibrate only the buttons selected in the button list. Buttons that are not selected are marked "excluded" (grey), and their calibration values stay unchanged.
- Added an animation to the calibration guide. It shows when to press, hold, release, or not touch a button. If you release a button before it is fully pressed, only that press is repeated.

## Other changes

- The connection error screen now reminds you to check that RapidJAM is in WebConfig/RNDIS mode.
- Updated the user guides (English and Japanese) for the new calibration steps.

# RapidJAM Configurator v0.8.0（日本語）

## 主な変更

**磁気スイッチの校正結果の信頼性を向上しました。** 校正では各ボタンを複数回の押す・離す動作で測定し、結果がそろわないチャンネルを知らせます。保存される値がより信頼できるものになります。

- 各ボタンを約 3 回押して測定します（結果がそろわない場合は最大 5 回）。測定値はこれらの押下から求めます。
- それでも押下の結果がそろわないチャンネルは「不安定」（オレンジ）と表示します。結果を確認し、必要なら再測定してください。
- ボタンを離した後にも未押下の値を測定し直します。ボタンを離して押し直したときに値の基準がずれる問題に対処しています。
- 未押下と押下の位置はチャンネルごとに 5 回サンプリングし、中央値を使って 1 回だけの突発的な値を除外します。
- 「選択したボタンを校正」を追加しました。ボタン一覧で選んだボタンだけを校正できます。選んでいないボタンは「対象外」（グレー）と表示し、校正値は変更しません。
- 校正ガイドにアニメーションを追加しました。押す・保持する・離す・触れない、の各タイミングを示します。ボタンを最後まで押し切る前に離した場合は、その押下だけをやり直します。

## その他の変更

- 接続エラー画面に、RapidJAM が WebConfig/RNDIS モードであることを確認する案内を追加しました。
- 新しい校正手順に合わせて利用ガイド（英語・日本語）を更新しました。
