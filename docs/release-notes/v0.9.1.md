# RapidJAM Configurator v0.9.1

## Changes

- The restore dialog no longer requires you to save a backup of the current settings first. The "Save current settings" step in the dialog is now optional, so you can restore right away if you already saved a backup from the sidebar or don't need one. The confirmation checkbox is still required.

## Download

- `rapidjam-configurator-x64-0.9.1.zip` (portable Windows x64 build)
- `rapidjam-configurator-x64-0.9.1.zip.sha256` (SHA-256 checksum)

The build is not code-signed. Windows SmartScreen may show a warning on first launch. See [DISTRIBUTION.md](../../DISTRIBUTION.md) for verification steps and the WebView2 requirement.

# RapidJAM Configurator v0.9.1（日本語）

## 変更点

- 復元ダイアログで、事前の現在設定のバックアップ保存が必須ではなくなりました。ダイアログ内の「現在の設定を保存」は任意になり、サイドバーで保存済みの場合や保存が不要な場合は、そのまま復元できます。確認チェックボックスは引き続き必須です。

このビルドにはコード署名がありません。初回起動時に Windows SmartScreen の警告が出ることがあります。検証手順と WebView2 の要件は [DISTRIBUTION.md](../../DISTRIBUTION.md) を参照してください。
