# RapidJAM Configurator v0.7.1

## Highlights

- Simplified the Windows ZIP for end users. It now contains only the app, a short README, the user guides, and the license notices, all in one folder.
- Added a bilingual `README.txt` (English first, then Japanese) to the ZIP.
- Merged the license files into `LICENSE.txt` and `THIRD-PARTY-NOTICES.txt`.
- Button faces are now drawn from an SVG layout.
- Drag text selection is disabled outside areas where copying makes sense.
- Added a settings screenshot to the README.

## Changes to the ZIP contents

The ZIP no longer includes `DISTRIBUTION.md` or the build audit files (SBOM, Cargo metadata, release manifest). These are kept for maintainers and are not published. Developer documentation is in [DISTRIBUTION.md](../../DISTRIBUTION.md).

## Download

- `rapidjam-configurator-x64-0.7.1.zip` (portable Windows x64 build)
- `rapidjam-configurator-x64-0.7.1.zip.sha256` (SHA-256 checksum)

The build is not code-signed. Windows SmartScreen may show a warning on first launch. See [DISTRIBUTION.md](../../DISTRIBUTION.md) for verification steps and the WebView2 requirement.

# RapidJAM Configurator v0.7.1（日本語）

## 主な変更

- Windows 版 ZIP を利用者向けに簡素化しました。アプリ本体、簡単な README、利用ガイド、ライセンス表記のみを 1 つのフォルダーにまとめています。
- ZIP に英日併記の `README.txt`（英語を先頭、日本語を後）を追加しました。
- ライセンスファイルを `LICENSE.txt` と `THIRD-PARTY-NOTICES.txt` にまとめました。
- ボタン表示を SVG レイアウトで描画するようにしました。
- コピーに適さない領域でのドラッグによる文字選択を無効にしました。
- README に設定画面のスクリーンショットを追加しました。

## ZIP の内容の変更

ZIP から `DISTRIBUTION.md` とビルド監査用ファイル（SBOM、Cargo メタデータ、リリースマニフェスト）を外しました。これらは開発者向けで、公開対象ではありません。開発者向けの説明は [DISTRIBUTION.md](../../DISTRIBUTION.md) を参照してください。

## ダウンロード

- `rapidjam-configurator-x64-0.7.1.zip`（Windows x64 向けポータブル版）
- `rapidjam-configurator-x64-0.7.1.zip.sha256`（SHA-256 チェックサム）

このビルドにはコード署名がありません。初回起動時に Windows SmartScreen の警告が出ることがあります。検証手順と WebView2 の要件は [DISTRIBUTION.md](../../DISTRIBUTION.md) を参照してください。
