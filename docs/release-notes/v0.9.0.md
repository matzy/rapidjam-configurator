# RapidJAM Configurator v0.9.0

## Highlights

**Settings backup and restore.** You can now save the current device settings to a file and restore them later.

- Open "Settings backup and restore" in the left sidebar, then use "Save settings backup" or "Restore settings from backup".
- Backups are saved as `rapidjam_backup_<date and time>.gp2040`, the same format as the GP2040-CE WebConfig backup. Configurator-only data (the full stroke length for the current device) is stored under the `rapidjamConfigurator` key, which WebConfig ignores.
- Restoring writes the settings to the device, then reads them back and compares them with the file.
- Backup files are validated strictly before anything is written to the device.
- Magnetic switch calibration values differ for each board. Restoring a backup from a different RapidJAM may make the buttons respond incorrectly.

## Other changes

- Updated vite to 8.3.3 (Dependabot security alert).

## Download

- `rapidjam-configurator-x64-0.9.0.zip` (portable Windows x64 build)
- `rapidjam-configurator-x64-0.9.0.zip.sha256` (SHA-256 checksum)

The build is not code-signed. Windows SmartScreen may show a warning on first launch. See [DISTRIBUTION.md](../../DISTRIBUTION.md) for verification steps and the WebView2 requirement.

# RapidJAM Configurator v0.9.0（日本語）

## 主な変更

**設定のバックアップと復元に対応しました。** 現在のデバイス設定をファイルに保存し、あとから復元できます。

- 左サイドバーの「設定のバックアップと復元」を開き、「設定をバックアップ保存」または「設定をバックアップから復元」を使います。
- バックアップは `rapidjam_backup_<日時>.gp2040` として保存されます。形式は GP2040-CE WebConfig のバックアップと同じです。Configurator 専用のデータ（現在のデバイスのフルストローク長）は `rapidjamConfigurator` キーに保存され、WebConfig では無視されます。
- 復元ではデバイスへ書き込んだあと、読み戻してファイルの内容と比較します。
- バックアップファイルは、デバイスへ書き込む前に厳格に検証します。
- 磁気スイッチの校正値はボードごとに異なります。別の RapidJAM のバックアップを復元すると、ボタンが正しく反応しなくなることがあります。

## その他の変更

- vite を 8.3.3 に更新しました（Dependabot のセキュリティアラート対応）。

## ダウンロード

- `rapidjam-configurator-x64-0.9.0.zip`（Windows x64 向けポータブル版）
- `rapidjam-configurator-x64-0.9.0.zip.sha256`（SHA-256 チェックサム）

このビルドにはコード署名がありません。初回起動時に Windows SmartScreen の警告が出ることがあります。検証手順と WebView2 の要件は [DISTRIBUTION.md](../../DISTRIBUTION.md) を参照してください。
