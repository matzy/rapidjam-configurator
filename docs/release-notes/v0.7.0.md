# RapidJAM Configurator v0.7.0

## Highlights

- Adjustable stroke amount per model.
- Standard-mode actuation force limit, with an expert mode toggle.
- Improved press guidance during magnetic switch calibration.
- Button labels and physical legends follow the selected input mode (including XInput and PlayStation/Xbox naming).
- English user guide and README added (English first, Japanese follows). MIT license added.
- Japanese user guide updated for the current version.

## Download

- `rapidjam-configurator-x64-0.7.0.zip` (portable Windows x64 build)
- `rapidjam-configurator-x64-0.7.0.zip.sha256` (SHA-256 checksum)

The build is not code-signed. Windows SmartScreen may show a warning on first launch. See [DISTRIBUTION.md](../../DISTRIBUTION.md) for verification steps and the WebView2 requirement.
